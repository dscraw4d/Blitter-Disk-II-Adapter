# Publishing with GitHub Desktop

Suggested repository name:

`Blitter-Disk-II-Adapter`

Suggested description:

`USB interface project for mounting real Apple II DOS 3.3 and ProDOS disks on modern Windows and Linux PCs using an original Disk II drive.`

## GitHub Desktop steps

1. Unzip this repository package to a normal folder on your PC.
2. Open **GitHub Desktop**.
3. Choose **File > Add Local Repository**.
4. Browse to the unzipped `Blitter-Disk-II-Adapter-GitHub-RevB` folder.
5. If GitHub Desktop says it is not yet a Git repository, choose **Create a Repository**.
6. Use repository name `Blitter-Disk-II-Adapter`.
7. Do **not** choose a license template yet unless you have decided which license you want.
8. Commit the initial files with a message such as:
   `Initial public Revision B prototype documentation`
9. Click **Publish repository**.
10. Decide whether the repository should be public or private, then publish.
